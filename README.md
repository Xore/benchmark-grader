# benchmark-grader

A Bun + React 19 review dashboard for LLM coder-benchmark runs. It reads
benchmark run data from disk and serves a browser UI for browsing runs,
coder artifacts, compile diagnostics, and per-case human grades.

## Run it

```sh
bun install
bun run server.ts   # or: bun start
```

Listens on `http://localhost:3020` by default.

## Configuration

| Variable | Default            | Meaning                          |
|----------|--------------------|----------------------------------|
| `PORT`   | `3020`             | HTTP port                        |
| `RUN_DIR`| `/tmp/roster-run`  | Root of the benchmark run data   |

Expected layout under `RUN_DIR`: `transcripts/<runId>/transcripts.jsonl` and
`transcripts/<runId>/coder-artifacts/`, plus `grades/<id>.json` for grades.
Run data is local-only and is not committed to this repository.

## Layout

- `server.ts` — Bun HTTP server, reads run data from `RUN_DIR`
- `verify.ts` — benchmark verification helper
- `src/` — dashboard UI (`app.tsx`, answer chunking, Shiki tokenizer, theme)
- `tmpl/` — Astryx template references (shell-nav, ai-chat, file-explorer, ide)
- `AGENTS.md` — generated by `astryx init`
